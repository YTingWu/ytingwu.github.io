# 我的賣場（shop.html）規格

2026-11-17 與 Bruce 訪談定案。快速計算（index.html）的計算邏輯與版面不變，「我的賣場」是進階功能。

## 1. 頁面

- 新頁 `shop.html`，header 名稱「我的賣場」。頁首只有標題與一行副標；「資料只存在這台裝置的瀏覽器，不需要登入蝦皮」的說明放在頁面最下方，並在「⋯」選單的備份區塊頂端再提醒一次。
- 只用 12/11 新制費率。
- 三個分頁：**自建商品**、**蝦皮商品**、**賣場設定**（2026-11-18 改版，原本是商品總覽／調價與庫存／賣場設定）。打開頁面回到上次停留的分頁（localStorage `shopee_myshop_tab`）；第一次打開時有蝦皮商品就開蝦皮商品，沒有就開自建商品。蝦皮匯入後開蝦皮商品；快速計算的舊設定搬進來時開自建商品。
- 賣場列：左邊賣場下拉選單，右邊一個「⋯」選單，分「賣場」（新增、刪除）與「備份」（匯出 JSON、從 JSON 還原、匯出 CSV）兩組。賣場名稱在「賣場設定」最上方修改（失去焦點即存）。
- 賣場列正下方是設定摘要（賣家類型 · 免運方案 · 蝦幣回饋 · 稅務 · 修改），在「自建商品」「蝦皮商品」顯示，切到「賣場設定」分頁時隱藏。
- 快速計算與自建商品是同一份資料（2026-11-18 合併，見第 4 節）。

## 2. 資料模型

存在 localStorage `shopee_myshop_v1`（與快速計算的 `shopee_calculator_configs_v1` 分開）。

### 賣場層（每個賣場一份）

| 欄位 | 值 | 對應快速計算 |
|---|---|---|
| seller | general／mall／shop | `seller` |
| shipPlan | ship1／ship2（免運方案一／方案二） | `shipping`（快速計算的 both 只是同時顯示兩案，賣場只選一案） |
| cashback、cashbackTerm | 0／1.5／2.5、long／short | 同名 |
| tax | 0／1／5／5_plus | `tax` |
| hasProdInv | 有商品進項發票的**預設值**；商品沒單獨設定時套用 | `hasProdInv`（帶到快速計算的是商品實際套用的值） |
| hasFeeInv | 有手續費進項發票 | `hasFeeInv` |
| first5 | 蝦皮小舖每月前 5 筆免成交手續費 | `first5` |
| （金流與系統處理費） | 固定 2.5%（不分期）。信用卡分期看買家選擇，只在快速計算試算；從快速計算加入時不帶分期 | — |
| lowMargin | 低利潤門檻 %，預設 5 | （新增） |
| shopeeShopId | 第一次匯入蝦皮檔時記住 | （新增） |

> 訪談時寫的「出貨 1 件／2 件」是筆誤：計算結果的兩個維度是「一般日／促銷檔期」×「免運方案一／方案二」。方案是賣場層設定，所以總覽只剩「一般日／促銷檔期」兩欄。

### 商品層

| 欄位 | 說明 |
|---|---|
| name、note | 名稱、備註（可搜尋） |
| cost | **只有自建商品用**：商品進價（可空＝待補進價）。蝦皮商品的進價在規格上（比照蝦皮），不沿用商品進價；功能上線前改版，不做舊資料搬遷 |
| costTax | 進價含稅／未稅；蝦皮商品的所有規格共用，在商品編輯視窗設定 |
| hasProdInv | 商品進項發票：`null`＝跟隨賣場預設、`true`／`false`＝單獨設定。編輯畫面是勾選框（顯示實際值），手動切換才變成單獨設定，可「改回跟隨賣場」。2026-11-17 前的舊資料：賣場預設補 false，商品沒勾→null、有勾→true |
| frozen | 冷凍訂單 |
| preorder | 0／2／3（蝦皮匯入時依備貨天數：1 天＝0、2 天＝2、≥3 天＝3） |
| fee | `{ shopeeCatId, path, manualRate, manual }`：path 是 fee-new.json 的類別路徑，費率依賣場類型取一般或商城費率，費率表更新時跟著走；manualRate 是手動費率 |
| variations | 規格陣列 `{ id, name, price, stock, cost, draft }`。自建商品只有一個規格（不顯示規格，cost 不用）；蝦皮商品每個規格各自的 cost＝進價 |
| shopeeItemId | 蝦皮商品 ID（手動新增的為 null） |
| missingInLastImport | 最近一次匯入時檔案裡沒有 |

商品只存售價。從快速計算「算售價」模式加入時，存「一般日、方案一」的建議售價。

## 3. 自建商品、蝦皮商品的共用版面（2026-11-18 改版）

- **表格**：兩個分頁都用同一種緊湊表格（`<table>`、`table-layout: fixed`），桌機名稱欄吃剩餘寬度、其他欄固定寬。**手機不改卡片、不換行**：整張表在框內左右滑（`overflow-x: auto`，頁面本身不橫向捲動），勾選＋名稱欄 `position: sticky` 固定在左邊。
- 淨利欄：金額＋利潤率；淨利 < 0 紅色、利潤率 < lowMargin 黃底；沒費率顯示「請選類別」、沒進價顯示「待補進價」。滑鼠移上（桌機）或點擊（手機）浮出費用拆解。
- 名稱下方標籤：請選類別／請重選類別（警示色）、本次未匯入、費率類別、預購、冷凍、備註。
- 摘要卡片各頁只算自己的商品，「虧本」「待補進價／類別」可點擊套用篩選。
- 分頁：每頁 10／20／50／100（蝦皮商品以商品為單位分頁）；搜尋、篩選、排序、切換賣場回到第 1 頁。
- ⋯ 選單用 Popper `strategy: fixed`，不會被捲動框裁掉。

### 自建商品

- 一個商品一列：勾選、名稱＋標籤、進價、售價、一般日淨利、促銷檔期淨利、⋯。**進價與售價直接在表格改**，打字中即時重算淨利。
- 表頭點擊排序（商品／進價／售價／一般日淨利／促銷檔期淨利）：由低到高 → 由高到低 → 恢復加入順序；沒有值的排最後。
- 篩選：全部、虧本、低於門檻、待補進價／類別。
- 工具列：搜尋、篩選、「新增商品」。勾選後只能批次刪除（不做批次調價）。
- ⋯：編輯、在快速計算開啟、複製、搬到／複製到其他賣場、刪除。
- 商品編輯視窗：名稱 → 進價／售價（蝦皮商品隱藏，改在規格上）→ 進價含稅 → 成交手續費 → 預購 → 發票／冷凍 → 備註（最下面）。成交手續費與快速計算同一個樣式：`[數字][%][查詢]`，直接打數字＝手動費率；「查詢」選類別後帶入該類別費率，下方註明類別（依賣場類型取一般／商城費率，隨費率表更新）。
- 沒有商品時顯示「新增商品」「到快速計算試算後儲存」。

## 4. 快速計算與自建商品合併（2026-11-18）

為了不讓使用者分不清「快速計算的已存設定」和「自建商品」，兩邊改成同一份資料（`shopee_myshop_v1` 的自建商品）。

- **快速計算左側列表＝所有賣場的自建商品**，依賣場分組（只有一個賣場時不顯示賣場名稱）；每筆顯示進價、售價、費率，底部連到賣場總覽。點一下載入：帶入**賣場設定＋商品欄位**（`quickCalcQuery`），所以兩邊算出的數字一致；目前載入的項目標示出來。刪除＝刪掉自建商品（先確認）。
- **「儲存到賣場」**（取代原本的「儲存目前設定」與「加入我的賣場」兩個按鈕）：視窗有商品名稱、存到哪個賣場（或「用目前的設定建立新賣場」），設定和目標賣場不同時列出差異並說明獲利依賣場設定計算。從列表載入的商品多一組選項「更新這個商品」（預設）／「另存成新商品」。更新時費率沒變就保留原本的類別設定。存完留在快速計算頁。只存商品層欄位（進價、含稅、售價、費率、預購、冷凍）；信用卡分期不存。
- 「用獲利率算售價」模式存的售價是「一般日、方案一」的建議售價。
- **類別跟著走**：快速計算用「查詢」點選類別後，記住類別路徑（網址參數 `cat`，以 ` > ` 分隔；費率欄下方顯示「類別：…」），使用者手動改費率欄才清除（`calculator-new.js`，可信的 input 事件）。存到賣場時，有類別就存成依類別的費率（`fee.mode = 'category'`，依賣場類型取一般／商城費率、隨費率表更新），賣場頁標籤顯示類別名稱；從列表載入時把類別帶回快速計算。更新商品時，快速計算有類別就用新的類別。
- **舊資料搬遷**：`shopee_calculator_configs_v1` 裡 `rates: 'new'` 的設定，在第一次打開快速計算或賣場頁時搬進**第一個賣場**的自建商品（沒有賣場就用第一筆的設定建「我的賣場」），搬完從舊清單移除並提示一次。先存賣場、成功才改寫舊清單（`migrateQuickConfigsInStorage`）；搬走的原始設定另存一份在 `shopee_calculator_configs_v1_migrated`（只增不刪，供人工救回）。賣場資料存在但無法解析時不搬（不覆蓋）；讀取後舊清單已被其他分頁改動時不搬（避免重複）。注意：搬進來的商品改用賣場設定計算，原本每筆各自的賣家類型、稅務、蝦幣、免運方案不保留。舊制（`rates` 不是 `new`）的設定留在原清單，舊制頁 `old.html` 照舊使用。
- 賣場頁移除「從已存設定匯入」、建立賣場時「沿用已存設定」、以及 `shop.html?add=1` 的加入流程。

## 6. 蝦皮匯入

### 檔案

賣家中心 → 我的商品 → 批次工具 → 下載商品模板：「價格及庫存」（`mass_update_sales_info_*.xlsx`）和「備貨天數」（`mass_update_dts_info_*.xlsx`）。

實測格式（2026-11-17，Bruce 的賣場 96 商品／725 規格）：

- 第 1 列機器欄名，第 2 列 A 欄 `sales_info`／`dts_info`（用來辨識，順序不拘），D 欄是蝦皮賣場 ID；第 3 列中文欄名；第 4–6 列說明；第 7 列起是資料，一列一個商品選項。
- sales：A 商品ID、B 商品名稱、C 商品選項ID、D 商品規格名稱、E 主商品貨號、F 商品選項貨號、G 價格、H GTIN、I 庫存、J 最低購買數量、K 失敗原因。
- dts：A 商品ID、B 主商品貨號、C 商品名稱、D 商品選項ID、E 商品規格名稱、F 商品分類（`101355 - Stationery/...`）、G/H 備貨天數限制、I 備貨天數、J 失敗原因。
- 所有儲存格（含價格、庫存）都是 shared string。
- `sheetView` 的 `activePane="bottom_left"` 不符合規格，openpyxl 讀不了；頁面用 JSZip＋DOMParser 自己解析。

### 規則

- 新商品需要兩份都有；只更新既有商品時可單份（只更新該檔有的欄位）。缺檔時提示並附步驟與截圖。
- 去重：商品用商品 ID，規格用選項 ID。
- 重複匯入：名稱、售價、分類、備貨天數、庫存以新檔為準；進價、備註、手動指定的類別保留；檔案沒有的商品保留並標「本次未匯入」。匯入前顯示「新增／更新／未出現」數量確認。
- 有未匯出的調價草稿時，確認畫面列出來讓使用者選保留或捨棄（預設保留）。
- 庫存 0 照常匯入、照常顯示。
- 賣場綁定：第一次匯入記住蝦皮賣場 ID；之後不符時警告並建議切換／新建賣場；兩份檔案賣場 ID 不同時擋下。

### 分類對應費率

- `shopee-categories.json`：賣家中心 `/api/v3/category/get_category_tree/` 的全部分類（2026-11-17 抓取，2289 個節點），格式 `{ id: [parentId, 中文名稱] }`。
- 對應方法：分類 ID → 中文路徑 → fee-new.json。完全相同或「費率表葉節點是路徑前綴」（費率表只列到上層時套用上層費率）。比對前先去掉控制字元（例如「USB藍芽\x08接收器」）。
- 別名（名稱或層級不一致）寫在 `shop-data.js` 的 `CATEGORY_ALIASES`。
- 2026-11-17 實測：1979 個葉分類中，完全相同 671、套用上層 1304、需別名或手動 4；Bruce 的 44 個分類全部自動對到。
- 對不到的讓使用者手動選，結果依分類 ID 記在瀏覽器，下次自動套用。
- **更新分類樹**：登入賣家中心，在任一頁的 console 執行 `fetch('/api/v3/category/get_category_tree/')`，把 `data.list` 攤平成上述格式（注意名稱裡可能有換行或控制字元）。

## 7. 蝦皮商品

- 沒有蝦皮商品時只顯示「上傳蝦皮檔案」的空狀態。
- 摘要卡片以**規格**為單位：商品／規格數、虧本規格、平均利潤率（一般日／促銷檔期，規格平均）、待補進價／類別（規格數）。
- 資料時間一行；工具列：搜尋（商品或規格名稱）、篩選（全部、虧本、低於門檻、待補進價／類別、已修改待匯出、已匯出待蝦皮更新、本次未匯入）、「重新匯入」、「批次調整 ▾」。
- 表格：**商品標題列**跨滿整列（勾選＝選這個商品列出的所有規格、名稱、標籤、⋯；內層 sticky，手機橫滑時留在畫面上）＋**規格列**（勾選、規格名稱與「待匯出／已匯出」標記、進價、售價、庫存、兩個情境淨利）。進價、售價、庫存都可直接改，售價打字中即時重算淨利。
- 進價直接生效（不會寫進蝦皮檔案）；售價與庫存存成草稿 `draft: { price, stock, status }`，status 為 `pending`（待匯出）或 `exported`（已匯出，待蝦皮更新），不覆蓋蝦皮匯入的值；改過的格子標色並顯示原值。
- **批次調整 ▾**（按鈕上顯示勾選數）：選一個動作後在表格上方展開該動作的輸入列，套用後收起；沒勾選時需要勾選的項目停用。
  - 漲跌 % 或加減金額（取到個位／十位／尾數 9，以蝦皮原價為基準，重複套用不累加）
  - 依目標利潤率回推售價（`calculateRequiredPrice`，一般日或促銷檔期；缺進價或類別的略過）
  - 設定庫存、設定進價（進價直接生效）
  - 恢復勾選的修改、全部恢復（全部恢復先確認）
  - 刪除勾選的規格：只刪勾到的規格，規格全刪光的商品整個刪掉；確認視窗列出商品與規格，並說明下次匯入會再出現、填過的進價不保留
  - 一鍵清除蝦皮資料：清掉這個賣場的蝦皮商品（含進價、草稿）、「價格及庫存」原檔、綁定的蝦皮賣場 ID，回到上傳畫面；自建商品與賣場設定保留；先確認
- ⋯（商品層）：編輯（類別、預購、發票、冷凍、進價含稅）、單一規格時在快速計算開啟、搬到／複製到其他賣場（保留蝦皮連結；目標賣場已有同一個蝦皮商品就擋下）、刪除整個商品。蝦皮商品不能在同賣場複製。
- 底部固定一列：待匯出數量＋「產生蝦皮批次更新檔」。分頁標籤上顯示待匯出數量。
- 時效：資料時間優先用蝦皮檔名結尾的 `yyyyMMddHHmmss`（台灣時間，檔案產生時間；docProps 的日期固定是 2006 年不能用），讀不到才用匯入時間。超過 24 小時在匯入、蝦皮商品分頁、下載確認畫面都提醒（不擋）。
- 下次匯入時：蝦皮的值與 exported 草稿一致就清除草稿；不一致就列出來，提醒可能上傳失敗，請看蝦皮檔的「失敗原因」欄。

### 產生批次更新檔

- 以使用者最後上傳的「價格及庫存」原檔為底（存在 localStorage，base64），只改 G（價格）和 I（庫存）。
- 只保留有修改的規格列，第 1–6 列原樣保留，資料列重新連續編號（避免把期間賣掉的庫存蓋回去）。
- 新值寫成 shared string（附加到 sharedStrings.xml，更新 count／uniqueCount），與蝦皮原檔一致。
- **模板第 4 列規定價格、庫存都必填**：只改售價的規格，庫存會以匯入時的數字寫回（反之亦然）。確認畫面照實列出每列會寫入的售價與庫存，並說明這一點。
- 下載前確認：列出每筆的商品／規格、寫入售價（舊→新，附淨利變化）、寫入庫存。
- 待匯出但不在目前原檔裡的規格（例如已在蝦皮刪除）：這次略過並列出，修改保留。
- 先把「已匯出」存進 localStorage，存成功才下載；匯入存檔失敗時整份還原。
- 檢查：價格 1–499999 的整數；同一商品最貴規格不超過最便宜的 5 倍（以修改後的全部規格計算）；庫存為 ≥0 的整數。違規擋下並標出。
- 原檔不在時請使用者重新上傳。
- **未驗證**：產生的檔案能否被蝦皮接受，要在賣家中心實際上傳一次才知道。

## 8. 備份

- 匯出／匯入整份資料 JSON（匯入時取代或合併，先確認）。
- 每個賣場可匯出商品 CSV（含 BOM，Excel 開啟不亂碼）。

## 9. 首次使用

兩步引導：建立賣場（預設值）→ 新增第一個商品、在快速計算按「儲存到賣場」，或從蝦皮匯入。
