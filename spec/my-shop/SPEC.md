# 我的賣場（shop.html）規格

2026-11-17 與 Bruce 訪談定案。快速計算（index.html）的計算邏輯與版面不變，「我的賣場」是進階功能。

## 1. 頁面

- 新頁 `shop.html`，header 名稱「我的賣場」。頁首只有標題與一行副標；「資料只存在這台裝置的瀏覽器，不需要登入蝦皮」的說明放在頁面最下方，並在「⋯」選單的備份區塊頂端再提醒一次。
- 只用 12/11 新制費率。
- 三個分頁：**商品總覽**、**調價與庫存**、**賣場設定**。
- 賣場列：左邊賣場下拉選單，右邊一個「⋯」選單，分「賣場」（新增、改名、刪除）與「備份」（匯出 JSON、從 JSON 還原、匯出 CSV）兩組。
- 賣場列正下方是設定摘要（賣家類型 · 免運方案 · 蝦幣回饋 · 稅務 · 分期 · 修改），在「商品總覽」「調價與庫存」顯示，切到「賣場設定」分頁時隱藏。
- 快速計算在「儲存目前設定」旁加「加入我的賣場」按鈕：帶目前的 query string 到 `shop.html?add=1&...`。

## 2. 資料模型

存在 localStorage `shopee_myshop_v1`（與快速計算的 `shopee_calculator_configs_v1` 分開）。

### 賣場層（每個賣場一份）

| 欄位 | 值 | 對應快速計算 |
|---|---|---|
| seller | general／mall／shop | `seller` |
| shipPlan | ship1／ship2（免運方案一／方案二） | `shipping`（快速計算的 both 只是同時顯示兩案，賣場只選一案） |
| cashback、cashbackTerm | 0／1.5／2.5、long／short | 同名 |
| tax | 0／1／5／5_plus | `tax` |
| hasProdInv | 有商品進項發票的**預設值**；商品沒單獨設定時套用 | `hasProdInv`（帶到快速計算的是商品實際套用的值） |
| hasFeeInv | 有手續費進項發票 | `hasFeeInv` |
| first5 | 蝦皮小舖每月前 5 筆免成交手續費 | `first5` |
| （金流與系統處理費） | 固定 2.5%（不分期）。信用卡分期看買家選擇，只在快速計算試算；從快速計算加入時不帶分期 | — |
| lowMargin | 低利潤門檻 %，預設 5 | （新增） |
| shopeeShopId | 第一次匯入蝦皮檔時記住 | （新增） |

> 訪談時寫的「出貨 1 件／2 件」是筆誤：計算結果的兩個維度是「一般日／促銷檔期」×「免運方案一／方案二」。方案是賣場層設定，所以總覽只剩「一般日／促銷檔期」兩欄。

### 商品層

| 欄位 | 說明 |
|---|---|
| name、note | 名稱、備註（可搜尋） |
| cost、costTax | 商品統一進價（可空＝待補進價）、含稅／未稅 |
| hasProdInv | 商品進項發票：`null`＝跟隨賣場預設、`true`／`false`＝單獨設定。編輯畫面是勾選框（顯示實際值），手動切換才變成單獨設定，可「改回跟隨賣場」。2026-11-17 前的舊資料：賣場預設補 false，商品沒勾→null、有勾→true |
| frozen | 冷凍訂單 |
| preorder | 0／2／3（蝦皮匯入時依備貨天數：1 天＝0、2 天＝2、≥3 天＝3） |
| fee | `{ shopeeCatId, path, manualRate, manual }`：path 是 fee-new.json 的類別路徑，費率依賣場類型取一般或商城費率，費率表更新時跟著走；manualRate 是手動費率 |
| variations | 規格陣列 `{ id, name, price, stock, cost(覆寫，可空), draft }`；手動新增的商品只有一個規格 |
| shopeeItemId | 蝦皮商品 ID（手動新增的為 null） |
| missingInLastImport | 最近一次匯入時檔案裡沒有 |

商品只存售價。從快速計算「算售價」模式加入時，存「一般日、方案一」的建議售價。

## 3. 商品總覽

- 每列一個商品；規格多於一個時，售價與獲利顯示最低～最高，展開看各規格（含庫存）。
- 欄位：名稱、售價、一般日淨利／利潤率、促銷檔期淨利／利潤率。蝦皮小舖只有一個情境。
- 標色：淨利 < 0 紅色；利潤率 < lowMargin 黃色。未填進價的標「待補進價」，不計入摘要。
- 排序：點表頭（商品／進價／售價／一般日淨利／促銷檔期淨利）切換「由低到高 → 由高到低 → 恢復加入順序」，淨利以金額排序；沒有值的（待補進價、未選類別）不論升降冪都排最後。手機表頭只留排序按鈕。搜尋（名稱＋備註）、篩選「待補進價」。
- 分頁：列表下方「每頁 10／20／50／100 筆」與頁碼，預設 10 筆；搜尋、篩選、排序、切換賣場都回到第 1 頁。「全選」只選本頁。
- 摘要卡片：商品數、虧本商品數、平均利潤率（一般日／促銷檔期）、待補進價／類別。「虧本商品」「待補進價／類別」可點擊，套用對應篩選（再點一次取消），與篩選下拉同步。
- 工具列一列：左邊搜尋／篩選，右邊「匯入▾」（從蝦皮商品檔、從快速計算已存設定）與「新增商品」。手機：搜尋滿寬一列，篩選、匯入、新增（後兩者只留圖示）一列。
- 全選：桌機在表頭第一欄，手機是清單上方的獨立列；商品計數與「刪除勾選的 N 個商品」在表頭上方的小字列。
- 賣場沒有商品時，清單區顯示「從蝦皮匯入」「新增商品」「從快速計算已存設定匯入」三顆按鈕。
- 展開時顯示費用拆解，另有「在快速計算開啟」（用 query string 帶到 index.html）。
- 進價可直接在列上填（商品統一進價），規格可在展開後覆寫。
- 操作：新增、編輯、複製、刪除、搬到／複製到其他賣場、勾選批次刪除。
- 桌機用表格，手機用卡片。

## 4. 從快速計算加入

彈窗選擇目標賣場，或「用目前設定建新賣場」。只帶商品層欄位；快速計算的賣場層設定與目標賣場不同時，列出差異並說明獲利依賣場設定重算。

## 5. 從快速計算已存設定匯入

在賣場頁可選已存設定匯入成商品，只取商品層欄位，舊資料不動。舊設定只有費率數字，匯入後為手動費率並標「請重選類別」。

## 6. 蝦皮匯入

### 檔案

賣家中心 → 我的商品 → 批次工具 → 下載商品模板：「價格及庫存」（`mass_update_sales_info_*.xlsx`）和「備貨天數」（`mass_update_dts_info_*.xlsx`）。

實測格式（2026-11-17，Bruce 的賣場 96 商品／725 規格）：

- 第 1 列機器欄名，第 2 列 A 欄 `sales_info`／`dts_info`（用來辨識，順序不拘），D 欄是蝦皮賣場 ID；第 3 列中文欄名；第 4–6 列說明；第 7 列起是資料，一列一個商品選項。
- sales：A 商品ID、B 商品名稱、C 商品選項ID、D 商品規格名稱、E 主商品貨號、F 商品選項貨號、G 價格、H GTIN、I 庫存、J 最低購買數量、K 失敗原因。
- dts：A 商品ID、B 主商品貨號、C 商品名稱、D 商品選項ID、E 商品規格名稱、F 商品分類（`101355 - Stationery/...`）、G/H 備貨天數限制、I 備貨天數、J 失敗原因。
- 所有儲存格（含價格、庫存）都是 shared string。
- `sheetView` 的 `activePane="bottom_left"` 不符合規格，openpyxl 讀不了；頁面用 JSZip＋DOMParser 自己解析。

### 規則

- 新商品需要兩份都有；只更新既有商品時可單份（只更新該檔有的欄位）。缺檔時提示並附步驟與截圖。
- 去重：商品用商品 ID，規格用選項 ID。
- 重複匯入：名稱、售價、分類、備貨天數、庫存以新檔為準；進價、備註、手動指定的類別保留；檔案沒有的商品保留並標「本次未匯入」。匯入前顯示「新增／更新／未出現」數量確認。
- 有未匯出的調價草稿時，確認畫面列出來讓使用者選保留或捨棄（預設保留）。
- 庫存 0 照常匯入、照常顯示。
- 賣場綁定：第一次匯入記住蝦皮賣場 ID；之後不符時警告並建議切換／新建賣場；兩份檔案賣場 ID 不同時擋下。

### 分類對應費率

- `shopee-categories.json`：賣家中心 `/api/v3/category/get_category_tree/` 的全部分類（2026-11-17 抓取，2289 個節點），格式 `{ id: [parentId, 中文名稱] }`。
- 對應方法：分類 ID → 中文路徑 → fee-new.json。完全相同或「費率表葉節點是路徑前綴」（費率表只列到上層時套用上層費率）。比對前先去掉控制字元（例如「USB藍芽\x08接收器」）。
- 別名（名稱或層級不一致）寫在 `shop-data.js` 的 `CATEGORY_ALIASES`。
- 2026-11-17 實測：1979 個葉分類中，完全相同 671、套用上層 1304、需別名或手動 4；Bruce 的 44 個分類全部自動對到。
- 對不到的讓使用者手動選，結果依分類 ID 記在瀏覽器，下次自動套用。
- **更新分類樹**：登入賣家中心，在任一頁的 console 執行 `fetch('/api/v3/category/get_category_tree/')`，把 `data.list` 攤平成上述格式（注意名稱裡可能有換行或控制字元）。

## 7. 調價與庫存

- 每列一個規格，可改售價與庫存，旁邊即時顯示修改後的一般日／促銷檔期淨利與利潤率，改過的格子標色。
- 批次工具（勾選後套用）：漲跌 % 或加減金額（可選取整）、依目標利潤率回推售價（用 `calculateRequiredPrice`，只套用已填進價的規格）、設定庫存、恢復（單一商品或全部）。
- 修改存成草稿 `draft: { price, stock, status }`，status 為 `pending`（待匯出）或 `exported`（已匯出，待蝦皮更新）；不覆蓋蝦皮匯入的值。總覽用草稿價格計算獲利並標示。
- 時效：資料時間優先用蝦皮檔名結尾的 `yyyyMMddHHmmss`（台灣時間，檔案產生時間；docProps 的日期固定是 2006 年不能用），讀不到才用匯入時間。超過 24 小時在匯入、調價分頁、下載確認畫面都提醒（不擋）。
- 下次匯入時：蝦皮的值與 exported 草稿一致就清除草稿；不一致就列出來，提醒可能上傳失敗，請看蝦皮檔的「失敗原因」欄。

### 產生批次更新檔

- 以使用者最後上傳的「價格及庫存」原檔為底（存在 localStorage，base64），只改 G（價格）和 I（庫存）。
- 只保留有修改的規格列，第 1–6 列原樣保留，資料列重新連續編號（避免把期間賣掉的庫存蓋回去）。
- 新值寫成 shared string（附加到 sharedStrings.xml，更新 count／uniqueCount），與蝦皮原檔一致。
- **模板第 4 列規定價格、庫存都必填**：只改售價的規格，庫存會以匯入時的數字寫回（反之亦然）。確認畫面照實列出每列會寫入的售價與庫存，並說明這一點。
- 下載前確認：列出每筆的商品／規格、寫入售價（舊→新，附淨利變化）、寫入庫存。
- 待匯出但不在目前原檔裡的規格（例如已在蝦皮刪除）：這次略過並列出，修改保留。
- 先把「已匯出」存進 localStorage，存成功才下載；匯入存檔失敗時整份還原。
- 檢查：價格 1–499999 的整數；同一商品最貴規格不超過最便宜的 5 倍（以修改後的全部規格計算）；庫存為 ≥0 的整數。違規擋下並標出。
- 原檔不在時請使用者重新上傳。
- **未驗證**：產生的檔案能否被蝦皮接受，要在賣家中心實際上傳一次才知道。

## 8. 備份

- 匯出／匯入整份資料 JSON（匯入時取代或合併，先確認）。
- 每個賣場可匯出商品 CSV（含 BOM，Excel 開啟不亂碼）。

## 9. 首次使用

兩步引導：建立賣場（預設值，或從一筆快速計算已存設定帶入）→ 新增第一個商品、從已存設定匯入、或從蝦皮匯入。
